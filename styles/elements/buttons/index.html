css/modules/elements/_buttons.scss

A <button> inside .rd needs no class: it gets the default look, as a form field does, and so does an <input> of type submit, button or reset. .button gives the same look to a link or any other element. Variants, sizes and layouts are classes on top. A button is inline, so buttons placed side by side share a line, and it is as wide as its label, in a card, a panel or a form group too.

Link as a button 
<button type="button">Button element</button>
<a class="button" href="/styles/elements/">Link as a button</a>

The default is a white control with a light frame that turns black under the pointer and grey while pressed. Its text stays black on a dark surface such as .card-inverted, on a button and on a link alike: the card's link colour is for text links.

Until v0.7.2 a bare button was a block-level grey pill; it is inline now. To give one a line of its own, put it in a block (a <p>, a <div>), or take the full width with .button-block. The .block utility works on a <button> but not on a.button: .button comes after the utilities in the stylesheet and has the same weight.

Variants

.button-primary
The one action that matters on the screen, on the --signal accent. The fill is the signal shaded by 15%, so the white label reads at 5.4:1; the pure blue would give 4.1:1, short of WCAG AA.
.button-secondary
The default look by name: for a link (class="button button-secondary"), or to restore it inside a container that re-colours its buttons.
.button-ghost
No frame until the pointer is on it. For toolbars and secondary actions in a row. Its label is the text colour of the surface it sits on (--primary-text-color) and its hover tint a share of that colour, so it reads on a light page and on .card-inverted alike.
.button-danger
A destructive action, on --color-danger, shaded the same way (5.3:1).
.button-link
Reads as a text link, keeps the button's box, so it lines up with the buttons next to it.
<button class="button-primary" type="submit">Save</button>
<a class="button button-ghost" href="…">Details</a>

On a link, a variant needs .button next to it; on a <button> it does not.

On a dark surface

The filled variants keep their colours. The ghost and link variants have no fill, so their labels take the text and link colours of the surface.

Link button

Sizes

.button-md is the default, named so it can be restored inside a container that sets another size. A size sets --button-padding-x, --button-padding-y and --button-font-size; at the default size a button is as tall as a text field.

<button class="button-sm" type="button">Small</button>
<button class="button-lg button-primary" type="button">Large</button>

Icons

An rd-icon-* glyph before or after the label sits at an even gap from it, whatever whitespace the markup has, and the button stays on the text line like one without a glyph. .button-icon is a square for a glyph alone: as tall as a text button of the same size. Give it a name with aria-label.

<button type="button"><span class="rd-icon-download"></span> Download</button>
<button type="button">Next <span class="rd-icon-arrow_forward"></span></button>
<button class="button-icon" type="button" aria-label="Settings">
    <span class="rd-icon-settings"></span>
</button>

States

Hover, pressed
Each variant darkens its frame or its fill. The change is a colour fade (--button-transition); nothing moves. With reduced motion it is instant.
Keyboard focus
The library's focus ring, in --signal.
disabled
Faded in every variant, with the default pointer. aria-disabled="true" looks the same and keeps the button focusable, so it can still explain why it is off. A link has no disabled: give it aria-disabled="true" and remove its href.
aria-busy="true"
The label hides, so the button keeps its width, and a ring in the label colour turns in its place. With reduced motion the ring stands still. The script that sets the attribute also ignores clicks while it is set. The ring needs a <button> or a .button link: an <input> cannot draw it.
Disabled link 
<button class="button-primary" type="submit" aria-busy="true">Save</button>

Group

.button-group joins buttons into one segmented row: neighbours share a border, and only the outer corners are rounded. A pressed toggle (aria-pressed="true") keeps the pressed look of its variant: grey under a black frame for the default, the darkest fill for a primary. The hovered or focused button is lifted, so its whole frame and the focus ring show.

<div class="button-group" role="group" aria-label="Period">
    <button type="button" aria-pressed="false">Day</button>
    <button type="button" aria-pressed="true">Week</button>
    <button type="button" aria-pressed="false">Month</button>
</div>

Full width

.button-block takes the full width of its container, for a phone layout or a narrow column. A glyph and its label stay centred together.

<button class="button-block button-primary" type="button">Download the report</button>

Tokens

TokenDefaultSets
--button-radiusvar(--space-xs) (4px)Corner radius. 999px makes a pill.
--button-padding-x / -yvar(--space-md) / var(--space-sm)Inner spacing; the sizes change them.
--button-font-sizevar(--font-size-md)Label size; the sizes change it.
--button-font-weightvar(--font-weight-normal)Label weight.
--button-transitionbackground and border colour, 0.15sThe hover and press fade (off with reduced motion).
--button-bg / --button-text / --button-border-colorvar(--white) / var(--primary-color) / var(--border-color)The default look's colours.

A variant only fills six colour slots, which the default look reads: the three above, and --button-bg-hover (by default the same fill), --button-border-color-hover (--primary-color) and --button-bg-active (--bg-color). Set them on a class or an element to re-colour a button without a new variant:

.button-brand {
    --button-bg: var(--brand-color);
    --button-border-color: transparent;
    --button-bg-hover: var(--brand-color-dark);
    --button-border-color-hover: transparent;
}

A component's own buttons

The element defaults have type weight in every state, so one class overrides them, hover and press included. A text-like toggle drops the chrome with a single rule and keeps the focus ring:

.my-toggle {
    padding: 0;
    border: 0;
    background: none;
    color: inherit;
    font: inherit;
}

A RareCharts card (.rc-chart) draws its own buttons, so the element defaults stop at it. A button the page places inside a chart's controls row takes the library look only when it asks for it with .button.
