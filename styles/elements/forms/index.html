css/modules/elements/_forms.scss

Form fields need no class. Inside .rd, on a page or in an island, the plain elements take the library's look; a host form outside .rd never does. The library adds a frame, inner spacing, a 1rem text size and the states below. A field and a button of the default size are equally tall, so they line up in a row.

Text fields, textarea, select

The text fields are input without a type and the types text, email, password, search, tel, url and number. The date and time types (date, time, datetime-local, month, week) take the same frame and height; the browser draws their segments and picker inside it. The types submit, button and reset are buttons. A placeholder is --text-color-light (5.7:1 on white; the browser's own grey is 2.3:1). A textarea grows downwards only. A select draws its own arrow in the text colour; a list box (multiple or size) keeps the browser's.

Checkbox and radio

Drawn by the library (appearance: none): a 1em box that sits on the text line like a glyph, filled with --field-accent when checked. Wrap the control in its <label>: the whole line becomes the hit area. A checkbox set to indeterminate by script shows a bar.

<label><input type="checkbox" name="news"> Release notes</label>
<label><input type="radio" name="plan" checked> Monthly</label>

Range, colour, file

Minimal: the range takes the accent colour; the colour well is as tall as a text field; the file input's button is a small default button.

Groups, rows, help and errors

.form-group
One field: its label, the control, a help or error line, stacked. The fields take the group's width; a checkbox, a radio or a button keeps its own.
.form-row
Groups and a button side by side, their bottoms aligned so the button lines up with the fields. Stacked on a phone.
.form-help, .form-error
Small lines under a control. An error is in the body text colour and marked with the error glyph in --field-invalid-color: red text would read at 4:1, short of AA. Tie both to the control with aria-describedby.

<div class="form-group">

A <fieldset> gets a light frame and may shrink with its column; its <legend> is bold.

States

Hover, focus
The frame darkens under the pointer and turns to --field-accent on focus, inside the library's focus ring.
disabled
A grey field with grey text and the default pointer. The label of a disabled checkbox or radio dims with it.
Invalid, valid
Only after the user has had a go: :user-invalid and :user-valid match once a field was edited or its form submitted, so an untouched form shows no errors. The frame turns --field-invalid-color; a field that asked for something (required, pattern) turns --field-valid-color once it is right. A script marks a field with aria-invalid="true", which shows at once.

Tokens

--field-border-colorvar(--gray-trans)The frame: 3.5:1 on white, the 3:1 a field's outline needs (WCAG 1.4.11).
--field-radiusvar(--button-radius)Corner radius; a checkbox takes half.
--field-padding-x / -y12px / var(--button-padding-y)Inner spacing; -y follows the button so the heights match.
--field-accentvar(--signal)Checked boxes and radios, the range, the focused frame.
--field-invalid-colorvar(--color-danger)The frame of an invalid field and the error glyph.
--field-valid-colorvar(--color-success)The frame of a required field once it is right.

Inside a chart

A RareCharts card (.rc-chart) owns its controls, so these defaults stop at it. The page's own checkboxes and selects that a chart moves into its controls row keep the chart's compact look.
