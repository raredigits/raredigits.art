Tips

Stop thinking about decorations, start thinking about the value.

The only thing that matters is the data your audience came for. Design, layouts, make-up and decorations are just your tools to highlight the value.

Imagine you have 30 secs to pitch your data. What would you say? What decision maker need to know? How would you present it? What would you highlight? What would you hide?

That's it. That's the only thing that matters. Delete the noise. Make your audience satisfied.

Charts Backlog

Features and chart types planned for future releases.

Feature API sketch Description
Annotations

Options for marking up the chart area with reference context. The base annotations API (vertical and horizontal point/range markers) ships in v0.9.5 — see Annotations — and on the dated Bar since v0.9.8_6. Items below are follow-ups.
Callouts and image overlays callouts: [{ x, y, text, image, dx, dy }] Text callouts and image overlays anchored to data coordinates or pixel positions inside the chart area. Distinct from annotations: callouts are free-form content at arbitrary (x, y) rather than axis-aligned markers. The data project (Churchbook) asks to bring this before 1.0 (annotations on Bar shipped in v0.9.8_6): its milestone stories (validator and project timelines — jails, renames, network halt) need labeled events on time series.
Band series

The band (confidence-ribbon) series ships on RareCharts.Line in v0.9.6 — see Bands. Items below extend it.
Bands on Time Series and Dual Axes type: 'band' on RareCharts.TimeSeries / RareCharts.DualAxes Wire the same { date, lower, upper } band series into the other date-based chart classes. Useful for confidence ranges on a zoomable price feed or alongside a bar/line dual-axis layout. Currently band rendering lives only in Line.
New chart types
Candlestick RareCharts.Candlestick OHLCV candlestick chart for price and financial data visualization.
Hierarchies RareCharts.Hierarchies Spatial hierarchy views — treemap, pack, sunburst, cluster — over the tree contract that shipped in v0.9.8_2 (see Hierarchical Bar for the linear outline and the node shape; Donut drills the same tree).
Scatter RareCharts.Scatter Two-metric point chart: [{ x, y, label?, size?, color? }] with optional size/color encoding, quadrant reference lines, and point labels. The workhorse of comparison analytics — risk vs. return, valuation vs. growth, any "rank N items on two axes" figure. Targeted for v0.9.8_8.
Heatmap RareCharts.Heatmap Matrix of [{ row, column, value }] cells colored by a diverging or sequential scale, with row/column labels and a cell tooltip. Covers sector-by-period performance grids and correlation matrices. Targeted for v0.9.8_8.
Waterfall RareCharts.Waterfall Sequential deltas from a start value to an end value with connector lines and subtotal steps — the earnings-bridge / P&L-decomposition staple of financial reporting. Targeted for v0.9.8_8.
Composition & stacking

Stacked bars ship on Bar in v0.9.8_2 — see Stacked Bar. Multi-series Line areas still overlap rather than accumulate; items below extend composition.
Stacked area stacked: true on RareCharts.Line area series Accumulate multi-series areas instead of overlapping them, including a 'percent' mode normalizing each slice to 100%. Targeted for v0.9.8_8.
Stacked bars on date slots [{ name, values: [{ date, value }] }] on RareCharts.Bar Extend the v0.9.8_2 categorical stack to the time-series bar mode: segments stacked per date slot, with the shared timeframe controls.
All chart types in MultiChart type: 'Donut' | 'Gauge' | 'DualAxes' | ... in charts descriptors Extend the MultiChart composition grid beyond Line and Bar to every chart class (an unknown type already warns and draws a Line since v0.9.8_6). Unblocks mixed dashboard blocks — a KPI gauge next to a trend line under one shared header. Targeted for v0.9.8_9.
Scales & transforms
Series rebase / normalization normalize: 'rebase' | 'percent' on RareCharts.Line Re-express every series relative to its value at the start of the visible window — rebase to 100 or cumulative percent change — so multi-asset comparisons share one axis. Recomputes on zoom/timeframe change, which is why it belongs in the chart rather than in data prep. Targeted for v0.9.8_9.
Bar series
Bar value labels on vertical bars and Dual Axes showValues: true on vertical RareCharts.Bar / RareCharts.DualAxes bars Horizontal Bar already prints values at bar ends (showValues, valueFormat; short and negative bars keep their labels since v0.9.8_4_1). Extend it to vertical bars — above positive bars, below negative ones — and to the bar series of Dual Axes.
Diverging bar chart RareCharts.DivergingBar Bar chart centered on a shared baseline for before/after, left/right, positive/negative, or category comparison layouts. Targeted for v0.9.8_8.
Map
Map overlays and labels layers: [{ type, data, ... }] Add overlay layers to maps for extra information such as points, routes, bubbles, labels, markers, or other contextual geographic annotations.
Clickable map regions onRegionClick: ({ feature, item, event }) => void or item.href Allow clicking a region to trigger navigation or custom actions. Intended for drill-down flows, region detail pages, dashboards, and linked geographic navigation.
Graph
Graph ownership layout view: 'ownership' Add an optional deterministic hierarchy for ownership and control chains: owners above, controlled entities below, direction made explicit, and percentages or relation labels shown when supplied. It is a specialized presentation over the general graph contract, not a required ownership-specific schema.
Graph cluster-view strategies configurable aggregation and layout Revisit cluster after relation filtering, richer edges and details are available. Explore pluggable strategies for community structure, industry roles, value chains, geography and ownership groups, with the current Louvain overview retained as a general default. Domain-specific grouping must be opt-in and may be supplied by the data source instead of inferred client-side.
Graph chrome styling icons, dark theme The footer tools (zoom, full screen, +N more, restore), one-line breadcrumbs and text-like controls shipped in v0.9.8_3. Left: proper icons instead of text glyphs for the tools, and a dark-theme pass over the tools, the hidden-node list and the details panel.
Time Series: analytics ranges

Requested by a donor for a website traffic report on RareCharts.TimeSeries: visits per hour, day and month, aggregated on the server. Targeted for v0.9.8_7. Charts that do not set the new options keep their current behaviour. The API sketches are provisional.
Calendar presets anchored to now timeframeAnchor: 'now' | 'dataEnd' (default 'dataEnd'); keys TODAY, WTD (with weekStart), MTD, YTD, rolling 24H, 7D, 30D, 12M Presets now count back from the last data point in rolling units, so 1D means 24 hours before the last point, not today. Calendar keys start at the beginning of the day, week, month or year in the chart's time zone; rolling keys stay rolling.
Resolution follows the window onTimeframeChange(({ key, extent }) => Promise<data>) with a loading state, or setData({ hour, day, week, month }) with resolution: { maxPoints } Switching from Year to Today shows hourly buckets instead of zooming into the daily series. The navigator keeps the full range at the coarse resolution. Each switch fires one callback with the key and the extent; buttons and brush stay in sync.
Custom range A Custom control in the range bar with from / to date inputs; key 'CUSTOM'; can be turned off Goes the same way as the preset buttons (setView and onTimeframeChange) and is styled by the library, so a page gets Today / Week / Month / Year / All time / Custom from options alone, without rebuilding the chart.
A time zone timeZone: 'UTC' | 'local' — the default xTickFormat by visible span shipped in v0.9.8_6 (%H:%M, %b %d, %b, %b '%y, %Y) One zone for parsing, ticks, tooltips and preset boundaries. Today a 'YYYY-MM-DD' string is read as UTC midnight while presets compute in local time, so month buckets shift west of UTC; '1M' from 31 March also overflows to 2 March. The span-aware default tick format shipped in v0.9.8_6; its ticks will follow the zone this item picks.
Comparison series compare: 'previousPeriod' or a second series The same metric for the previous period of equal length, aligned to the current window and drawn as a dashed line without area ("this week vs last week"). The tooltip shows it next to the main value.
Counts and gaps yFormat: 'number' as on Line; gaps: 'zero' | 'break' The default y format is dollars ('$' + ',.0f'); a count option keeps that default for existing charts. Missing buckets drawn as zero or as a break in the line (today a missing value is dropped and the line joins its neighbours).
Interactivity
Legend series isolation legendInteractive: true Clicking a legend item isolates that series. All others are dimmed. Clicking the active item or double-clicking restores all series. Targeted for v0.9.8_9.
Arbitrary in-chart labels labels: [{ x, y, text, dx, dy, color }] or per-series labelFormat Render custom text labels directly inside the chart area for lines, bars, and highlighted values. Intended for editorial annotations, direct labeling, and reducing reliance on legends or tooltips.
Branding
Branding API RareCharts.setBrand(config) Global brand configuration applied to all chart instances: logo image (rendered as a watermark), accent color, and font family. Eliminates per-chart theme repetition in multi-chart dashboards.
