# RareCharts — ТЗ: Sankey (internal)

> **Непубличный файл** (см. `.eleventyignore`). Запрос от потребителя библиотеки (2026-10-07). Релиз — **0.9.8_3 Flows I** вместе с Graph A1–A3 и видом Graph `flow` ([SPEC-GRAPH-FLOW](./SPEC-GRAPH-FLOW-INTERNAL.md)); `MapFlow` — в 0.9.8_4 ([SPEC-GRAPH-MAPFLOW](./SPEC-GRAPH-MAPFLOW-INTERNAL.md)); решение — в [ROADMAP-INTERNAL](./ROADMAP-INTERNAL.md).
>
> Experimental-класс (как Graph и MapFlow): вне semver-гарантии 1.0, заморозку не задевает. В [API-INVENTORY](./API-INVENTORY-INTERNAL.md) заводится **до** выпуска.

**Зачем:** показать, как величина перетекает между этапами/категориями: бюджеты и их расходование, денежные следы, воронки, балансы. Узлы стоят колонками, ленты между ними — потоки, толщина ленты = `value`.

**Профиль потребителя:** чаще всего 2–3 колонки, иногда больше. Сроки терпят, но класс входит в ближайший релиз. Мобильная версия нужна; рабочая гипотеза — поворот на 90° (колонки становятся рядами), подтверждается тестами на реальных данных.

## 1. Контракт данных

```js
new RareCharts.Sankey('#chart', {
  title, subtitle, source, note,          // общие текстовые слоты

  orientation: 'horizontal' | 'vertical' | 'auto',   // auto: vertical при ширине ≤ mobileBreakpoint
  mobileBreakpoint: 480,

  nodeWidth: 12,                           // толщина узла по оси потока, px
  nodePadding: 12,                         // зазор между узлами колонки, px
  nodeAlign: 'justify' | 'left' | 'right' | 'center',
  nodeSort: null | 'value' | (a, b) => number,       // null = порядок входа (стабильно, без перестановок)
  iterations: 6,                           // релаксация раскладки d3-sankey

  linkColor: 'source' | 'target' | 'type' | 'gradient' | string,
  linkOpacity: 0.45,
  linkTypes: { … },                        // контракт Graph/MapFlow, общий

  labels: 'auto' | 'outside' | 'inside' | false,
  minLabelSize: 10,                        // px высоты узла; ниже — подпись только в тултипе
  valueFormat: v => string,                // в подписях и тултипах
  showValues: true,                        // значение рядом с подписью узла

  tooltipFormat: ({ node }) => html,
  linkTooltipFormat: ({ link }) => html,  // общий слой связей (см. Graph A3)

  animate: true, duration: 600, ease: 'cubicOut',
});

chart.setData({
  nodes: [
    { id: 'tax', label: 'Налоги', color?: '…', column?: 0 },
    { id: 'health', label: 'Здравоохранение' },
  ],
  links: [
    { source: 'tax', target: 'health', value: 120, type?: 'grant', label?: '…', /* любые поля */ },
  ],
});
```

- `nodes` можно не передавать: тогда узлы выводятся из `links` (id = label). Явный `nodes` задаёт подписи, цвета и порядок.
- `column` — ручная привязка узла к колонке (поверх `nodeAlign`); нужна, когда смысл колонок задан данными («источники / посредники / получатели»).
- Имена `links`/`source`/`target` — общий словарь слоя связей; `from`/`to` и `flows` принимаются как алиасы (решение шага 0, API-INVENTORY → «Flows — общий слой связей»).
- Повторные ссылки одной пары с разным `type` — **отдельные ленты** (в отличие от простого графа Graph), с одинаковым `type` — суммируются с предупреждением.
- Узел, у которого вход ≠ выход, рисуется по максимуму из двух (поведение d3-sankey); разница — видимый «остаток», как у нормализатора иерархии. Явное отображение остатка — не в v1.

### Валидация (понятные ошибки вместо пустого канваса)
- **Цикл** (A→B→A, в т.ч. самопетля) → `throw` с перечислением рёбер цикла. Циклические сэнки — не в v1.
- `value` ≤ 0, `NaN`, не число → ребро отбрасывается с `console.warn` (как адаптеры).
- `source`/`target` указывает на несуществующий узел при явном `nodes` → `console.warn`, ребро отбрасывается.
- Пустые данные → пустое состояние без исключения.

## 2. Раскладка

- Алгоритм — порт `d3-sankey` 0.12.3 в `src/core/sankey.js` (≈350 строк), с сохранением его лицензионного уведомления (BSD-3-Clause, проверить при переносе). Пакет как зависимость **не** ставим: он не обновлялся с 2020 года и тянет `d3-array@1-2`/`d3-shape@1`, которые продублируются в бандле рядом с d3 v7.
- Порт — чистая функция без DOM: `layoutSankey({ nodes, links }, { width, height, nodeWidth, nodePadding, align, sort, iterations })` → координаты узлов и лент. Покрывается юнит-тестами отдельно от рендера.
- Вертикальная ориентация = та же раскладка с переставленными осями (`width ↔ height`, `x ↔ y`) + `d3.linkVertical`-путь. Отдельного алгоритма нет.
- Детерминизм: одинаковые данные → одинаковая картинка (нет случайности; при `nodeSort: null` порядок узлов внутри колонки — порядок входа).

## 3. Рендер

- Узлы — прямоугольники, цвет: `node.color` → `linkTypes`/палитра темы по индексу.
- Ленты — `path` с `stroke-width` = толщина потока, `fill: none`. `linkColor: 'gradient'` — `linearGradient` от источника к цели; id градиентов — уникальные на экземпляр (известная проблема фиксированных id из инвентаря не повторять).
- Подписи узлов: `auto` — у первой колонки снаружи слева, у последней снаружи справа, у средних — со стороны большего свободного места; при `vertical` — над/под узлом. Узлы ниже `minLabelSize` — без подписи (только тултип). Коллизии подписей внутри колонки — скрытие меньшего узла.
- Hover узла → подсветка всех входящих и исходящих лент, остальные приглушены. Hover ленты → подсветка ленты и двух её узлов. Клик по ленте пиннит тултип (общий слой связей), клик мимо — снимает. Хит-зона тонкой ленты ≥ 8px.
- Тултипы по умолчанию: узел — label, вход/выход (`valueFormat`); лента — `source → target`, value, доля от выхода источника, `label`/`type`.
- Легенда — только при `linkColor: 'type'`, реюз legend-компонента; фильтрация типов как в Graph (скрытые типы убирают ленты, раскладка не пересчитывается — чтобы картинка не прыгала).
- Тема (`defaultTheme`/`darkTheme`), текстовые слоты, `applySvgA11y` — как у остальных классов.

## 4. Мобильная версия

Основная гипотеза — **поворот на 90°** при `orientation: 'auto'` и ширине контейнера ≤ `mobileBreakpoint`: колонки становятся рядами, поток идёт сверху вниз, подписи — горизонтально над/под узлами, высота контейнера растёт от числа рядов (`rowHeight`, по умолчанию ~140px на ряд).

Проверить на трёх наборах (2, 3 и 5 колонок; 8–25 узлов) при 375 / 480 / 768 px:
1. Вертикаль — читаются ли подписи средних рядов, не сливаются ли тонкие ленты.
2. Фоллбэк A — горизонтальная ориентация с `minWidth` и горизонтальной прокруткой контейнера.
3. Фоллбэк B — горизонталь с подписями только у крайних колонок, средние — в тултипе.

По итогам — зафиксировать дефолт `auto` и записать результат в FIELD-NOTES. Если вертикаль не проходит на 5 колонках, это становится рекомендацией в доке, а не блокером.

**Рекомендация для доки:** до 4 колонок и до ~30 узлов; больше — агрегировать мелкие потоки в «Прочее» на стороне данных. Жёсткого лимита в коде нет.

Ресайз — через общий `ResizeObserver` базового `Chart`; переключение ориентации на брейкпоинте — без пересоздания экземпляра.

## 5. A11y и движение

- `applySvgA11y` (accessible name из title), `role="img"` + `aria-label` на узлах и лентах («Налоги → Здравоохранение: 120»).
- Фокус с клавиатуры на узлах (Tab), Enter — пин тултипа; лента доступна через тултип узла (список входов/выходов).
- Текстовая альтернатива: опция `tableFallback: true` рендерит скрытую таблицу `source | target | value` (или документируем рецепт — решить в ревью инвентаря).
- `prefers-reduced-motion` → `motionDuration()`, без анимации появления. Гард входной анимации — по паттерну Bar из 0.9.8_2 (синхронный флаг + `interrupt()`), не через `on('end')`.

## 6. Не в v1 (осознанно)

Циклы · ручное перетаскивание узлов · многоуровневый drill-down · анимированные «частицы» по лентам · явная отрисовка остатка узла (вход ≠ выход) · встраивание в `MultiChart` (идёт с `MultiChart → все типы` в 0.9.8_6).

## 7. Демо, тесты, acceptance

Страница `/charts/sankey/` (публичная, с пометкой experimental), демо на синтетике:
1. **Бюджет:** 2 колонки (доходы → расходы), 10 узлов — базовый случай.
2. **Денежный след:** 3 колонки, `linkColor: 'type'` + легенда, ленты с `label` и пин-тултипом.
3. **Воронка/баланс:** 5 колонок — демонстрация рекомендуемого предела и мобильного поведения.

Тесты (`test/sankey.test.js`):
- раскладка: сумма толщин лент = высота узла; узлы колонки не пересекаются; детерминизм;
- валидация: цикл → throw, отрицательные/NaN → warn + drop, висячий id → warn;
- smoke-рендер в обеих ориентациях, `orientation: 'auto'` переключается по ширине;
- уникальность id градиентов у двух экземпляров на странице;
- тултип ленты пиннится и снимается.

**Acceptance:**
- все три демо рендерятся из чистых данных и конфига, без кастомного кода;
- на 375 px демо 1 и 2 читаемы без прокрутки страницы вбок; демо 3 — читаемо или явно задокументировано ограничение;
- тёмная тема, reduced motion, клавиатура — проверены в браузере;
- класс заведён в API-INVENTORY, опции сверены с общим контрактом (`duration`, форматтеры, `linkTypes`, имена `links`/`source`/`target` — общие с Graph/MapFlow);
- полный тест-сюит зелёный, размер бандла до/после записан в CHANGELOG.
